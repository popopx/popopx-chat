# POPOPX Chat bots API: typeScript types

This TypeScript library provides auto-generated types for bots API: commands and responses, events and all types they use.

It is used in [popopx-chat](https://www.npmjs.com/package/popopx-chat) Node.js library.

[API reference](https://github.com/popopx/popopx-chat/tree/stable/bots).
